# 术语表：HUD / FUI 设计口径

## Glossary — HUD / FUI Design Vocabulary

> 统一三个技能与文档的用词。画面中没有解说，定义由画面与行业通用用法归纳得出。

## 界面类型

- **HUD（Heads-Up Display）**：运行时信息层，承载状态、指令、反馈。不是装饰性科幻贴图。
- **FUI（Fictional UI）**：虚构界面的视觉设计门类，多用于影视 / 概念；HUD 多用于真实运行。
- **GUI**：可交互图形界面（菜单、按钮、窗口）。与 HUD 的差别在「是否以世界 / 仪表为中心」。
- **数据可视化**：用图形编码数据关系（图表、网络、力场）。可以独立存在，不必是 HUD。

## 空间关系

- **screen-space**：贴在最终画面平面，不随物体透视变化。
- **world-space**：锚定三维物体或空间坐标，随镜头透视变化；需要锚点与深度排序。
- **diegetic**：世界内实体设备上的界面（腕投、舱屏、手机），角色可看见 / 触摸；需物理痕迹与交互因果。

## 信息层级

- **环境层 ambient**：坐标、刻度、编号、细网格；亮度约 20–25%，不承载决策。
- **上下文层 context**：单位、量程、标签、状态词；亮度约 45–55%。
- **关键层 critical**：决策数值、告警、选中态；亮度约 90–100%，字号 ≥ 标签 2 倍。
- **净空 negative space**：刻意留出的无信息区，用来托住主体或强化告警。
- **数据密度节奏**：密区与疏区交替的编排；不等于「信息越多越专业」。

## 图形语言

- **引线 leader line**：连接 2D 标签与 3D 部件的细线，需端点与避让规则。
- **角标 register mark**：L 形或括弧形定位标记，可替代完整边框。
- **扫描线 scanline**：周期性横向纹理，模拟 CRT / 投影；过量降低可读性。
- **色差 chromatic aberration**：RGB 通道轻微错位，模拟镜头 / 投影，属介质痕迹。
- **bloom**：自发光溢出造成的辉光；过量糊字并抬高实时开销。
- **overdraw**：同一像素被多次绘制的渲染开销；多层半透明 + bloom 是主要来源。

## 工程与交付

- **参数化 widget**：可调尺寸 / 数量 / 量程 / 角度 / 状态的组件；改参数不重画。
- **真机测试 in-engine test**：在实际引擎或运行环境中验证 HUD，而非只在合成软件里看。
- **状态完备性**：空、载入、失败、越界、无权限等状态都有设计。
- **P0 / P1 / P2**：审计优先级。P0 影响读取关键值或安全；P1 影响效率与可信度；P2 打磨。
- **3 秒测试**：只看 3 秒，能否说出「当前状态 / 下一步动作 / 风险」。
- **灰阶测试**：去掉颜色后，信息层级是否仍成立。
- **25% 缩略测试**：把画面缩到四分之一，关键值是否仍可读。
