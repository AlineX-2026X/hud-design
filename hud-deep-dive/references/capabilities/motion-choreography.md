# 动效编排：进入、状态、常态与强调

HUD 动效只做四件事，各有明确职责：

| 类型 | 做法 | 时长 |
|---|---|---|
| 进入 | 交代结构：扫描线画出边框 → 模块错峰淡入 40–80ms → 数值 count-up → 锁定框落位 | 0–400ms |
| 状态变化 | 只动变化的那一条：条形填充、圆环扫过、数字翻牌；不整屏重绘 | 120–240ms |
| 常态呼吸 | 低幅慢周期，只改透明度或极小位移（≤5%），作用是「它还活着」 | 2–4s |
| 强调 | 关键动作做一次强动效，然后静止停留；不循环闪烁 | 一次性 |

配套原则：

- 同一时刻并发动画 ≤3，否则观众不知道该看哪。
- 动效跟随镜头：近景快、远景慢；HUD 随摄影机产生视差，而不是硬贴画面。
- 转场用局部重绘 + 数据滚动，避免整屏闪烁。
- 载入、失败、拒绝也是动效叙事的一部分（`LOADING`、`NO ENTRY`、`WORK IN PROGRESS`）。

## 步骤

1. 列动效清单：进入 / 状态 / 常态 / 强调，各对应哪些元素。
2. 排进入时间线：画框 0–120、模块错峰 40–80、数值滚动 80–160、锁定 40–80。
3. 定状态动画：每个变化只影响 1–2 个元素，120–240ms。
4. 定常态：2–4s 循环，透明度变化 ≤5%，同时循环 ≤2 个。
5. 定强调：一次性，结束即静止，给出停留时长。
6. 跟镜头：给 HUD 层加视差系数（近 1.0 / 中 0.7 / 远 0.4），检查与摄影机运动同向。
7. 验收：录屏 10s 统计循环数；遮住 HUD 看画面是否仍成立；慢放检查有无整屏重绘；用户能否指出「刚才发生了什么变化」。

输出：动效时间线表（元素 / 触发 / 时长 / 缓动 / 并发）+ 视差参数 + 验收记录。

## 样例

一段极简 loading：纯黑起，细圆环逐步绘制，`LOADING` 出现，几何徽标落位，最后完全静止。整段只用「画—落—停」，没有多余粒子。**静止是设计的一部分**——它让「完成」可被感知。

## 边界

- 静态海报、单帧概念图不需要动效编排。
- 不把「持续扫描 / 闪烁」当科幻感：成熟样本在关键动作后都会静止。
- 真实工具里动效不能延迟信息出现：关键值必须立即可读，动画只做强调不做揭示。
- 眩晕与无障碍：避免大幅抖动、快速缩放、频闪，提供「减少动效」模式。
- 引擎内要算性能：全屏 bloom + 多层半透明动画会显著抬高开销。

## 依据

> `LOADING`：细圆环从缺口画到整圆，几何徽标落位后静止 —— 片头 loading 的逐帧过程
