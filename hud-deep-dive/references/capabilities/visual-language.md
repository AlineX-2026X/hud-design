# 视觉介质：色彩、字体与发光

科幻感主要来自**介质痕迹**，不是图形复杂度。

## 七条规则

- **单主色相 + 单告警色 + 深底**。主色相承载常态（青=数据、绿=生物医疗、琥珀=工业、洋红=赛博），告警色（橙 / 红）只用于异常、危险、越界、选中。
- **发光代替阴影**。不用投影分层，用自发光描边、bloom、半透明叠加；底色趋近纯黑，让发光成为唯一边界。
- **三级亮度**（100 / 55 / 22）配三级字号，形成稳定层级。
- **字体**：全大写、宽字距 0.1–0.2em；数字等宽；标题与数值靠字重 / 字号区分，不靠颜色。中文模式不加大字距，字号地板 +1px。
- **介质痕迹 ≤3 种**：扫描线、噪点、色差、轻微抖动、玻璃反射。超过三种开始糊字。
- **告警三重编码**：颜色 + 形状（三角 / 横幅 / 环）+ 文字。
- **克制样本**：有的标题只用极低亮度单色细字，证明「不发光也能成立」。

## 步骤

1. 按领域选主色相：数据=青、医疗=绿、工业=琥珀、危险=红、赛博=洋红 / 青。
2. 建色彩语义表：normal / warn / critical / selected / disabled，各给色值与用途。
3. 定亮度与字号阶梯（3 级 + 单位字号），用灰阶测试验证层级。
4. 定边框语言：自发光描边 + 角标；圆角默认 0–2px。
5. 选 ≤3 种介质痕迹并给强度上限：噪声 ≤5%、色差 ≤2px、扫描线透明度 ≤10%。
6. 排文字：全大写字距 0.1–0.2em；数值等宽；单位降一级。
7. 验收：去色后层级成立；告警色只出现在语义位置；25% 缩略下细字仍可读；放大 200% 无锯齿 / 糊边。

输出：token 表（色 / 亮度 / 字号 / 字距 / 边框 / 痕迹强度）+ 应用示例。

## 样例

一块生物医疗 HUD：绿色主色相贯穿，橙色 `ANOMALY` 横幅 + 三角图标 + 文字构成告警三重编码，环形仪表与细胞簇用同色系不同亮度分层。整屏只有两种色相，橙色面积很小但一眼可见——告警色当语义资源用的典型。

## 边界

- 亮色场景（户外、车载白天、政务公开屏）不适用深底发光：改高对比浅底、减少 bloom。
- 告警色不得用于装饰：霓虹描边若同时承担告警语义就会失效。
- 发光过量会糊字并抬高实时渲染成本（overdraw）；影视合成可放宽，引擎内必须实测。
- 色觉障碍：红绿方案必须加形状 / 文字冗余，或改蓝橙。
- 不要用「深色 + 青色」当万能公式：工业、转播、纪实各有成熟语言。

## 依据

> `ANOMALY`（橙色横幅）与三角警告图标同屏 —— 生物医疗屏的告警三重编码
> `HUD / FUI REEL 2023`（极低亮度、单色、几乎无发光的标题） —— 极简标题画面
