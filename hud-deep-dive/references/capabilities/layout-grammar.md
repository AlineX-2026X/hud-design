# 屏幕分区与空间语法

HUD 不是把数据铺满屏幕，而是**先用功能区切开屏幕，再决定每一格放什么**。

## 五区

| 区 | 放什么 |
|---|---|
| 顶栏 | 全局状态、时间码、连接状态、任务阶段 |
| 左轨 | 输入与环境：传感器、轨道、坐标、姿态 |
| 右轨 | 清单与日志：可滚动表格、事件流、设备列表 |
| 中央舞台 | 3D 主体 + 锁定框 + 引线，必须留净空 |
| 底栏 | 操作与资源：燃料、电量、按键提示、状态机 |

三条配套规则让分区不呆板：

1. **边框不闭合**：L 形角标、括弧、虚线安全框代替四边封死的框，四边不同时封口。
2. **引线绑定**：二维标签用细线 + 端点指向三维部件，避免「数据在左、主体在右」的脱节。
3. **中央优先**：主体包围盒内不放文字，数据退到轨道与角落。

## 步骤

1. 列模块清单，按决策相关性排序。
2. 画五区骨架，标注每区模块数（单区 ≤3 个同级模块）。
3. 中央先留净空 ≥35% 画面面积，主体包围盒内文字数 = 0。
4. 分配：全局态上顶栏、环境输入上左轨、清单日志上右轨、操作资源上底栏。
5. 设计开口与角标，选 2–3 种标记，保证四边不全封。
6. 部件与数据用引线绑定，端点落在部件轮廓上，标签避让主体。
7. 验收：25% 缩略下能读出五区；中央第一眼落在主体；任一区不出现两个同级「最亮」。

输出：五区骨架图 + 模块分配表（区 / 模块 / 层级 / 数量）。

## 样例

一块综合工程屏：左上 `GRAVITY ASSIST` 双表盘（左轨）、中上轨道图（中央舞台）、右轨 20 行 `HEADER 273` 表格、中部 `ENGINE DIAGNOSTIC TOOL /READY` 剖面、底栏 `FUEL SYSTEM` 四联表盘。中央轨道图四周是大面积纯黑，所有模块退到四边——「分区先于装饰」的直接证据。

## 边界

- 数据点 <5、无 3D 主体时，五区语法过度设计，改用常规仪表盘栅格。
- 移动端竖屏、车载前装、AR 眼镜要用各自的安全区与视距规范，不能照搬 16:9 影视布局。
- 影视镜头允许装饰性分区；真实工具必须让每个区都有任务指向，否则删除。
- 分区不是「画格子」：没有层级的分区只是把混乱切成几块。
