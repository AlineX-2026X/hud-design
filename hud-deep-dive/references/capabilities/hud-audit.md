# HUD 诊断与优化（摘要卡）

> 完整版见独立技能 `hud-audit` 的 `SKILL.md`。本卡保留六轴与阈值，供只安装本技能时使用。

## 六轴

1. **可读性**：25% 缩略与灰阶下是否可读；字号、对比度、发光溢出、背景干扰。
2. **层级**：3 秒内能否定位状态 / 动作 / 风险；是否只有一层最亮最大。
3. **密度节奏**：是否全屏均匀密度；净空是否被装饰填满；密区有无标题与分隔。
4. **语义色彩**：告警色是否只用于异常；有无颜色 + 形状 + 文字三重编码。
5. **动效**：循环动画数量与时长；是否用循环闪烁代替一次性强调；是否整屏重绘。
6. **集成与性能**：透视 / 反光 / 遮挡是否成立；叠层与 bloom 是否过量；状态是否齐备。

阈值（工程约定）：净空 ≥30%、关键项 ≤5、告警色像素 ≤5%、同时循环 ≤2、状态动画 ≤240ms、叠层 ≤4、P0 ≤5 条。

## 输出

审计表：`轴 | 证据（时间点 / 区域）| 影响 | 修法 | 验收 | 优先级`。

按 P0 / P1 / P2 排序，每条写「证据 → 影响 → 修法 → 验收」；附「结论」「不改什么」「未决项」。

## 与相邻能力

- 要从零做 → `hud-design`；只改一层 → 对应深潜卡，但仍走六轴中的相关轴。
- 普通 App / 网页可用性评审 → 不适用。

## 边界

- 没有场景与任务时只给视觉层意见，声明局限。
- 不用影视审美替代可用性；不默认整体重做；不评版权与美术归属。
