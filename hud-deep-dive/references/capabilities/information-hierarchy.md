# 信息分层与数据密度节奏

数据密度不是「放多少」，而是**分几层、按什么节奏放**。

## 三层亮度

| 层 | 亮度 | 放什么 |
|---|---|---|
| 环境层 | ≈20–25% | 坐标、刻度、编号、细网格；只提供「这是一台仪器」的质感，不承载决策 |
| 上下文层 | ≈45–55% | 单位、量程、标签、状态词 |
| 关键层 | ≈90–100% | 决策数值、告警、选中态 |

密度节奏：高密度表列区必须与低密度净空区并置，边缘密、中央疏。全屏均匀密度会让眼睛没有落点。

数值排版：

- 关键值字号 ≥ 标签的 2 倍；单位比数值小 1–2 级、亮度更低。
- 数字用等宽字体；同屏小数位一致；量程与阈值常驻（`0–100`）。
- 用同构列 + 同位置指标做对比。
- 数值变化用滚动 / 翻牌，不整屏刷新。

## 步骤

1. 建数据清单：字段 / 单位 / 量程 / 精度 / 刷新率 / 异常阈值。
2. 给每项打层：环境 / 上下文 / 关键；关键项 ≤5。
3. 选编码：精确值→数字 + 单位；比例→条 / 环；趋势→微型折线；状态→点 + 文字；对比→同构列。
4. 排密度：密区压到轨道，中央留净空；每个密区给标题与分隔线。
5. 排数值：关键值 ≥2 倍标签字号；等宽；小数位统一；量程常驻。
6. 验收：3 秒内读到全部关键项；灰阶下三层仍可分；随机抽 5 个字段都能说出含义与单位。

输出：数据清单表 + 层级 / 编码映射 + 密度布局说明。

## 样例

一块电池对比页：三列完全同构——标题（Lead-Acid / LFP / NCM）→ 雷达图（容量 / 易用性 / 比能量 / 寿命 / 性能）→ `Energy Capacity` 双条对比（100% / 127% / 160%）→ 规格行。同位置同指标让跨列比较变成垂直扫描；雷达图承担「形状差异」，表格承担「精确值」，两者不重复。

## 边界

- 装饰性假数据（`HEADER 273` 这类字段）只能用于影视概念，不能进真实产品。
- 关键项超过 5 个时先拆屏或分页 / 分层展开，不要靠缩小字号硬塞。
- 对比页不要把不同指标混在同一根轴上。
- 环境层不是越多越好：低亮度细线在压缩、投影、移动端会直接消失，变成脏点。
