# 决策规则速查

| 能力 | 一句话规则 |
|---|---|
| HUD 设计全流程 | 先写三条决策问题，再分区、分层、定 token、建组件库、排动效、做集成验收。 |
| 诊断与优化 | 用可读性 / 层级 / 密度 / 语义色彩 / 动效 / 集成六轴审计，按 P0/P1/P2 出带验收的修复单。 |
| 屏幕分区与空间语法 | 五功能区切开屏幕，中央留净空，角标代替完整边框，引线绑定 2D 数据与 3D 主体。 |
| 信息分层与数据密度 | 三层亮度（环境 / 上下文 / 关键）+ 密疏并置 + 关键项 ≤5。 |
| 视觉介质 | 单主色相 + 单告警色 + 深底，发光替代阴影，介质痕迹 ≤3 种。 |
| 动效编排 | 进入画框—错峰—滚动—锁定，状态只动变化项，常态低幅呼吸，强调只做一次。 |
| 三种 HUD 与内嵌 | 先定 screen / world / diegetic 与「谁在看」，再补锚点、透视、遮挡、物理痕迹与后期匹配。 |

速查只给结论；需要依据与反例时读对应能力卡。
